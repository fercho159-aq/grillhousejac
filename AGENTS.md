# Grill House Jac

Antes de hacer cualquier cosa, lee [CONTEXTO.md](CONTEXTO.md) (qué es el proyecto, datos del
negocio, pendientes y relación con BarJac) y [marca/PALETA.md](marca/PALETA.md) (colores y tipografía).

- Proyecto hermano de `../barjac`: reutiliza su base (Next.js + Neon + panel admin).
- Datos del negocio: solo en `src/lib/site-config.ts`.
- Revisa que `npx tsc --noEmit` y `npm run build` pasen antes de subir cambios.
- No inventes datos del negocio (teléfono, dirección, horario, platillos ni precios).
- Textos del sitio en español de México.
